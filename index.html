    ⚡ Supabase PostgreSQL Table Schema

    WasteWatch AI connects to your Supabase instance (wfwphvxledodszghbkkq.supabase.co) to persist every captured trash photo and catalog its category, material, confidence, and disposal bin.

    To enable direct relational SQL queries in your Supabase SQL Editor, run this DDL script:

    CREATE TABLE IF NOT EXISTS public.user_images ( id TEXT PRIMARY KEY, category TEXT NOT NULL, item_name TEXT, material TEXT, confidence INT, bin TEXT, image_url TEXT, source TEXT, created_at TIMESTAMPTZ DEFAULT NOW() ); -- Enable public read & service-role write ALTER TABLE public.user_images ENABLE ROW LEVEL SECURITY; CREATE POLICY "Public Read Access" ON public.user_images FOR SELECT USING (true); CREATE POLICY "Full Access For App" ON public.user_images FOR ALL USING (true);
